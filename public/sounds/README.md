# 音效文件说明

本目录存放游戏音效文件。

## 需要的音效文件

请将以下音效文件放入此目录：

1. **phase_change.mp3** - 阶段切换音效
   - 时长：1-2秒
   - 建议：轻快的过渡音效

2. **game_start.mp3** - 游戏开始音效
   - 时长：2-3秒
   - 建议：激动人心的开场音效

3. **vote.mp3** - 投票音效
   - 时长：0.5-1秒
   - 建议：点击/确认音效

4. **eliminated.mp3** - 玩家淘汰音效
   - 时长：2-3秒
   - 建议：失败/淘汰音效

5. **victory.mp3** - 胜利音效
   - 时长：3-5秒
   - 建议：欢快的胜利音乐

6. **defeat.mp3** - 失败音效
   - 时长：2-3秒
   - 建议：失落的音效

7. **player_join.mp3** - 玩家加入音效
   - 时长：0.5-1秒
   - 建议：提示音

8. **player_leave.mp3** - 玩家离开音效
   - 时长：0.5-1秒
   - 建议：提示音

9. **ready.mp3** - 准备音效
   - 时长：0.5-1秒
   - 建议：确认音效

10. **notification.mp3** - 通知音效
    - 时长：0.5-1秒
    - 建议：轻柔的提示音

## 音效格式要求

- 格式：MP3
- 采样率：44.1kHz 或 48kHz
- 比特率：128kbps 或更高
- 声道：单声道或立体声
- 文件大小：建议每个文件 < 500KB

## 临时解决方案

如果暂时没有音效文件，系统会自动跳过播放，不会影响游戏功能。

你可以先使用简单的音效，后续再替换为更专业的音效。

## 自己制作音效

如果你想自己制作音效，可以使用：

1. **Audacity** - 免费开源音频编辑软件
2. **GarageBand** - Mac 自带音乐制作软件
3. **FL Studio** - 专业音乐制作软件

## 注意事项

- 确保音效文件名与代码中定义的一致
- 音效不宜过长，避免影响用户体验
- 音量适中，不要过大或过小
- 建议使用无版权或 CC0 许可的音效
